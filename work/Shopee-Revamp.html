Shopee Revamp

Redesigning key parts of the Shopee mobile experience to improve purchasing efficiency and usability.

This project focused on rethinking parts of the Shopee mobile app to improve the overall shopping experience. Working in a team, we explored how the current interface impacts user behaviour and identified opportunities to simplify the purchasing process through design.

Role UX Research, UX/UI Designer
Year 2024
Timeline 6 weeks
Link https://figmashort.link/XZZPNR

Problems & Goals

Shopee is designed to provide a fast and convenient shopping experience, but frequent users often face friction due to a cluttered interface and complex flows. Key actions such as finding products, applying vouchers, and completing purchases can feel unnecessarily time-consuming.

This leads to a fragmented experience where users need to navigate multiple steps and screens to complete simple tasks.

The goal of this project was to identify friction points in the purchasing journey and redesign key flows to make the experience faster, clearer, and more intuitive.

Process / Methodology

The project began with analysing Shopee's existing features and user flows. A heuristic evaluation was conducted to identify usability issues, followed by competitor analysis to understand how similar platforms handle product discovery and checkout.

User personas and journeys were then created to map out common behaviours and identify key moments where users experience friction.

A key focus of this project was rapid prototyping and iteration. The team established a testing workflow to ensure each iteration was validated and refined efficiently within the project timeline.

Low-fidelity prototypes were created and tested with active Shopee users. Feedback from each round was used to refine the flows, with multiple iterations conducted to improve clarity and reduce unnecessary steps.

This iterative approach helped the team quickly validate ideas and make informed design decisions.

Through this process, several key improvements were identified:

  • simplifying the checkout process using smart defaults
  • centralising voucher usage to reduce confusion
  • standardising filtering systems for better product discovery
  • re-prioritising navigation to better match user behaviour
  • reducing clutter by moving secondary features into contextual pop-ups

These were translated into refined wireframes and later high-fidelity mockups, supported by a style guide aligned with Shopee's existing design system.

Solution / Final Design

The final design focuses on simplifying the purchasing journey by reducing friction across key touchpoints. By streamlining checkout, improving navigation, and reorganising content, the app provides a more focused and efficient shopping experience.

The interface was refined to balance functionality and clarity, ensuring that users can quickly complete tasks without being overwhelmed by unnecessary elements. The design maintains familiarity with Shopee's existing system while improving usability through cleaner flows and better prioritisation.

Interaction Highlights:

  • Simplified Checkout - Reduced steps and introduced smart defaults to speed up purchases.
  • Unified Voucher System - Centralised voucher selection within checkout for better clarity.
  • Consistent Filtering - Standardised filtering system for easier product discovery.
  • Navigation Update - Reorganised bottom navigation to prioritise commonly used features.
  • Contextual Pop-ups - Secondary functions are hidden until needed, reducing interface clutter.
  • Notification Grouping - Categorised notifications to improve readability and relevance.

Impact & Reflection

Through iterative prototyping and testing, the project demonstrated how small design changes can significantly improve efficiency in a high-frequency task like online shopping. Users were able to complete key actions more quickly and with less confusion in later iterations.

This project also highlighted the importance of prioritisation in design. While many feature ideas emerged during testing, not all were implemented. Focusing on core user needs helped prevent feature bloat and kept the solution aligned with its main goal—simplifying the purchasing experience.
