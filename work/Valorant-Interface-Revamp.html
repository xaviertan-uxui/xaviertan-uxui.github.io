Valorant Screen Interface Revamp

Redesigning selected in-game interfaces for Valorant to create a cleaner and more intuitive navigation experience.

A UI revamp focused on reducing visual clutter and improving usability across key game screens, ensuring a smoother and more scalable interface.

Role UX Research, UX/UI Designer
Year 2024
Timeline 4 weeks
Link https://figmashort.link/MF5n6T

Key Screens / Visuals

UX Highlights

Agent Selection Filtering System

Introduced filtering within the agent selection interface to reduce cognitive load and improve navigation. This system also improves scalability as more agents are added over time.

Weapon Skin Collection Redesign

Redesigned the weapon skin gallery with a cleaner layout and added search functionality, making it easier for players to locate specific skins efficiently.
